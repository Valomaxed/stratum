# Bundled ground motion

`el-centro-1940.at2` is the **El Centro 1940 North–South, Peknold version**
distributed with the official OpenSees verification examples. It contains 1559
samples at 0.02 seconds in g. It is an example accelerogram, **not a newly
downloaded, hazard-selected PEER suite**. Other processed versions may differ.

Source: https://raw.githubusercontent.com/OpenSees/OpenSees/master/EXAMPLES/verification/elCentro.at2

Retrieved: 2026-10-29.

SHA-256 of the original bytes:
`fcc4417f9eba2083d8573010659d1e8177e1f795f47a8e8faa9382ef6fa753a0`.

No signal modification has been applied. The interface explicitly converts g
to m/s² using 9.80665 and applies only the stated amplitude scale factor.
User PEER records are processed in memory and are not saved on the server.
