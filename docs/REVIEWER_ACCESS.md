# Private academic review

This repository remains private. A CV link is usable only after the professor accepts repository access while signed in to GitHub.

Suggested CV annotation: **Private code repository; access available on request.**

- Repository: https://github.com/Valomaxed/stratum
- Author: Atharv Sharma ([GitHub](https://github.com/Valomaxed))
- Review entry point: [START_HERE.md](../START_HERE.md)

The author needs each recipient's GitHub username and must confirm the access level before invitations are sent. No recipient is inferred from a name or institutional email.

GitHub personal-account private repositories grant collaborators read **and write** access; they do not offer read-only collaborator roles. An organization-owned repository can provide finer roles for private review. No transfer or visibility change is included in this setup.

Source: [GitHub personal repository permissions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository).
