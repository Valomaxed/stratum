# Reviewing the project

The source and documentation are public at
https://github.com/Valomaxed/stratum. No collaborator invitation is needed to read
the repository.

Start with [the source guide](../START_HERE.md), then review the
[results](RESULTS.md) and [reproduction instructions](REPRODUCIBILITY.md).
The README identifies commands that run without large generated artifacts.

For a technical report, cite the repository revision and the relevant experiment
settings. Questions and reproducible defects can be reported through
[Issues](https://github.com/Valomaxed/stratum/issues).
